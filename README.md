# Browser Games Portal

This repository is an MVP scaffold for a browser-games portal.

ADMIN
- An initial admin user has been seeded for development:
  - Email: exclipsin2@gmail.com

How to run locally
1. Install deps: npm install
2. Run dev: npm run dev
3. Visit: http://localhost:3000

Security & legal
- This scaffold includes a tiny original local sample game (public/games/tiny-bounce). Do not import or host third-party games without verifying licenses.
